# Cyber-Threat-Analysis-Tool-Online-SIEM-Simulation-
Developed a SIEM-inspired cybersecurity analysis tool that processes multiple inputs including IP addresses, domains, HTTP headers, logs, and file uploads. Integrated live threat intelligence sources such as VirusTotal, AbuseIPDB, and AlienVault OTX to provide real-time reputation checks and enriched threat data. Implemented MITRE ATT&CK mapping to connect detected behaviors with known adversary techniques, assigned severity levels (Low to Critical) with reasoning, and generated SOC-style reports including both technical details and executive summaries. Additionally, the tool produced structured JSON-based threat map data for visualization of attack origins and targets. This project served as a prototype for understanding how SIEM tools like IBM QRadar, Exabeam, and Carbon Black function in a simplified, educational manner.
